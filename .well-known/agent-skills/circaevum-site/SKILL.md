# Circaevum site overview

Use when answering questions about circaevum.com, the public Graphics Library, or how Circaevum relates to the account app.

## What circaevum.com is

- **Public, auth-free** 3D timeline (Three.js + WebXR).
- **Not** the login app — accounts live at https://app.circaevum.com/
- Open source: https://github.com/Circaevum/three-circa

## Concepts

- **Y axis = time** (years upward; circadian zoom at day/hour levels).
- **XZ plane = place in orbital year** (Earth reference frame).
- **Events** = VEVENT-like objects with optional `render.timeseries` for biometrics (Garmin HR/sleep arcs).
